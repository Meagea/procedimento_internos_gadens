# Reembolsos Gadens

**[Abrir aplicativo](https://meagea.github.io/reembolsos-gadens/)**

Aplicativo de reembolsos para uso direto no navegador, sem instalação.
Inclui colaborador digitável, seleção de filiais, classes e projetos, rateio,
impressão direta em A4 e exportação para Excel.

Os relatórios ficam no perfil do navegador de cada pessoa. Faça backup em arquivo
para guardar o histórico e transferi-lo para outro navegador ou computador.
O site não recebe os relatórios preenchidos e não usa um banco de dados central.

Este repositório contém apenas os arquivos publicados no GitHub Pages.
O logo, o catálogo, o modelo Excel e a biblioteca de exportação estão incluídos no HTML.
O JSZip está incluído conforme a licença disponível em LICENCA-JSZIP.txt.
